# Track Runner

Особистий інтерактивний планер навчання. Один HTML-файл, без збірки і залежностей.

Перший трек уже заповнений — **AI Engineer Track** (5 steps, 18 фаз, 288 задач,
~330 годин), разом із наскрізними правилами і довідкою по іспитах.

## Що вміє

| Розділ | Що там |
|--------|--------|
| **Огляд** | Рівень і XP, відсоток плану, години за вагою фаз, активні дні, поточна фаза, наступні кроки, нещодавно закрите |
| **План** | Steps → фази → блоки → задачі. Пошук, фільтр «відкриті / закриті», матеріали фази, контрольні точки |
| **Курси** | Картки курсів зі статусом і повзунком прогресу; підсумок годин |
| **Матеріали** | Бібліотека посилань з типами й тегами, обране |
| **Журнал** | Щоденні нотатки за датами |
| **Довідка** | Наскрізні правила треку та довідка по іспитах (AI-901, AI-103, Databricks) |

Додавати, редагувати й видаляти можна все: треки, steps, фази, блоки, задачі,
матеріали, курси, записи. Кнопки редагування й видалення зʼявляються при наведенні
на шапку step або фази; для задач — праворуч у рядку. Видалення завжди питає
підтвердження у власному вікні (нативний `window.confirm` у пісочниці артефакта
ігнорується) і показує, скільки вкладених задач зникне разом.

Курси, матеріали і журнал спільні для всіх треків; плани — окремі для кожного.

## Збереження

- **Як опублікований Artifact** — стан пишеться у `data/state.json` поруч зі сторінкою.
  Зміни автоматичні, доступні з будь-якого пристрою за тим самим посиланням.
- **Локально з файлу** — стан у `localStorage` браузера. У меню (☰) є експорт
  і імпорт JSON, щоб перенести прогрес.

Локальний файл ні від чого не залежить: ні від акаунта, ні від мережі, ні від
жодного сервісу. Він працюватиме доти, доки в тебе є `index.html` і браузер.
Щоб перенести прогрес з опублікованої версії в локальну: ☰ → **Експорт у JSON**,
потім відкрити `index.html` і ☰ → **Імпорт з JSON**.

Індикатор у шапці показує режим: «Збережено» — на сервері, «На цьому пристрої» — локально.

## Запуск локально

```
open index.html
```

Файл самодостатній; з мережі тягне лише шрифти Google Fonts.

## Клавіші

- `1`–`6` — перемкнути розділ
- `/` — фокус у пошук (у розділі «План»)
- `Cmd/Ctrl + Enter` — зберегти відкриту форму
- `Esc` — закрити форму

## Дизайн

Тепла паперова база й глиняний акцент Claude плюс піксельний шар: тверді 2px рамки,
зсунуті тіні, сегментовані прогрес-бари, dither-сітка, іконки на `crispEdges`.
Шрифти — Alegreya (заголовки), IBM Plex Sans / Mono (текст і дані), Handjet (піксельні мітки).
Світла й темна теми йдуть за темою переглядача; перемикач у шапці.
